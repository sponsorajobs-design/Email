# Workspace Rule: Strict Project Boundary & Isolation

- **Workspace Scope**: This repository is exclusively for **Email Marketing**.
- **No External Cross-Contamination**: Under no circumstance should the agent query, reference, inspect, start, or link to processes from other projects (e.g. `jobs`, Next.js app).
- **Default Server Endpoints**:
  - Email Marketing Frontend: `http://localhost:5173` (Vite)
  - Email Marketing Backend: `http://localhost:8000` (FastAPI) / `http://localhost:8000/docs`
